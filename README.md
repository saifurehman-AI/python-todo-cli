# Python To-Do CLI Application

A command-line To-Do application built with Python that supports CRUD operations and persistent JSON storage.

## Features

- Add new tasks
- View tasks with numbering
- Mark tasks as completed
- Prevent duplicate task completion
- Delete tasks
- Save and load tasks using JSON
- Handle invalid task numbers and empty inputs

## Technologies Used

- Python 3
- JSON module
- File Handling
- Exception Handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the application:

   `python todo.py`

## Project Structure

- `todo.py` — Main application
- `CLI.json` — Automatically stores tasks (excluded from Git)
- `.gitignore` — Excludes local data and temporary files
- `README.md` — Project documentation

## Learning Outcomes

This project demonstrates Python fundamentals, functions, loops, conditional statements, CRUD operations, JSON persistence, and basic input validation.
